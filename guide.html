Pages web dynamiques avec JavaScript

Travaillez dans deux dossiers voisins : site-web pour la page web, api-http pour le serveur local. Chaque lien de cours indique la branche exacte ; respectez la casse et consultez la branche solution après avoir réalisé l’exercice. Conservez vos modifications dans une branche personnelle avant de changer de branche.

Page web

git clone https://github.com/beeformacademy/beeform-exercices-javascript-pages.git site-web
cd site-web
git switch P1C3-Exercice
npm install
npm run dev

API HTTP

Dans un autre terminal, depuis le dossier parent de site-web :

git clone https://github.com/beeformacademy/beeform-exercices-javascript-api.git api-http
cd api-http
npm install
npm start

L’API utilise localhost:8081. Gardez les deux terminaux ouverts. Les étapes CORS du cours et les commandes sources sont conservées ; cette API sert aux exercices locaux. Pour télécharger sans Git, sélectionnez la branche voulue, puis Code → Download ZIP et décompressez l’ensemble. Aucun accès en écriture au dépôt modèle n’est requis : utilisez une copie locale ou un fork personnel.
